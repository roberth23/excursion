Con esas columnas el cruce sería por `trx_id_event` y `trx_id_conc`, el tipo actual es `tipo_transaccion`, el medio actual es `trx_mediopago` y el mes sale de `trx_fch_mov`. Antes de armar las tablas de impacto hay que comprobar dos cosas para no asumirlas: que los valores de `ent_trx_loy` usan los mismos nombres que las tablas maestras, y que el cruce por evento y concepto encuentra a los movimientos (el evento puede venir vacío o con espacios).

Corre estas dos y pégame los resultados:

```sql
-- 1. Valores que hoy tiene ent_trx_loy
SELECT 'CO' AS pais, 'tipo_transaccion' AS campo, tipo_transaccion AS valor, COUNT(*) AS n
FROM `fif-loy-co-datalake-prod.trf_loy_co_entities_prd.ent_trx_loy` GROUP BY 3
UNION ALL
SELECT 'CO', 'trx_mediopago', trx_mediopago, COUNT(*)
FROM `fif-loy-co-datalake-prod.trf_loy_co_entities_prd.ent_trx_loy` GROUP BY 3
UNION ALL
SELECT 'PE', 'tipo_transaccion', TIPO_TRANSACCION, COUNT(*)
FROM `pe-fif-fun-productivo.trf_loy_pe_prd.ent_trx_loy` GROUP BY 3
UNION ALL
SELECT 'PE', 'trx_mediopago', TRX_MEDIOPAGO, COUNT(*)
FROM `pe-fif-fun-productivo.trf_loy_pe_prd.ent_trx_loy` GROUP BY 3
ORDER BY 1, 2, 4 DESC;
```

```sql
-- 2. Cuántos movimientos encuentran su fila en la tabla maestra (evento + concepto)
WITH m_co AS (
  SELECT DISTINCT COALESCE(TRIM(CODEVENT),'') AS e, TRIM(CODCONCE) AS c
  FROM `fif-loy-co-datalake-prod.trf_loy_co_master_prd.sfc_tipos_trx_medio_pago`
),
m_pe AS (
  SELECT DISTINCT COALESCE(TRIM(CODEVENT),'') AS e, TRIM(CODCONCE) AS c
  FROM `pe-fif-fun-productivo.trf_loy_pe_master_prd.sfc_tipos_trx_medio_pago`
)
SELECT 'CO' AS pais, COUNT(*) AS movimientos, COUNTIF(m.c IS NOT NULL) AS con_fila_en_maestra,
       COUNTIF(t.trx_id_event IS NULL) AS evento_nulo, COUNTIF(TRIM(t.trx_id_event) = '') AS evento_vacio
FROM `fif-loy-co-datalake-prod.trf_loy_co_entities_prd.ent_trx_loy` t
LEFT JOIN m_co m ON COALESCE(TRIM(t.trx_id_event),'') = m.e AND TRIM(t.trx_id_conc) = m.c
UNION ALL
SELECT 'PE', COUNT(*), COUNTIF(m.c IS NOT NULL),
       COUNTIF(t.TRX_ID_EVENT IS NULL), COUNTIF(TRIM(t.TRX_ID_EVENT) = '')
FROM `pe-fif-fun-productivo.trf_loy_pe_prd.ent_trx_loy` t
LEFT JOIN m_pe m ON COALESCE(TRIM(t.TRX_ID_EVENT),'') = m.e AND TRIM(t.TRX_ID_CONC) = m.c;
```

Las dos leen toda la historia de `ent_trx_loy`, así que pueden tardar. Con esos resultados escribo las tablas de impacto por mes.
